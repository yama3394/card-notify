カード利用通知メールを Gmail から自動取得したい場合は、Google Cloud Console で OAuth クライアントを用意してください（省略してダッシュボードへ進むこともできます）。

  1. Google Cloud でプロジェクトを作成し、Gmail API を有効化する。
  2. OAuth 同意画面を設定し、自分をテストユーザーに追加する。
  3. 認証情報で OAuth クライアント ID（デスクトップ） を作成し、 credentials.json をダウンロードする。

⚠️ OAuth 同意画面が「テスト中」ステータスのままだと、Gmail の refresh token は 約7日で失効し、通知が静かに止まります。自分専用で使う場合は本番モードへの 切り替えを強くおすすめします:

  1. Google Cloud Console →「APIとサービス」→「OAuth 同意画面」を開く。
  2. 公開ステータスの「アプリを公開」を押し、「本番環境」に切り替える （Google の審査は不要。確認画面はそのまま確定してよい）。
  3. 切り替え後の認証時に「このアプリは Google で確認していません」という警告が 出ますが、自分で作成した自分専用のアプリなので「詳細」→ 「（安全でないページに）移動」で進んで問題ありません。

ダウンロードした credentials.json をアップロードしてください。
